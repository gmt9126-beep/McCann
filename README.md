# Gabriella Testani — Motion Work

A flip-through presentation of selected motion design work, built as a single static page.

**Controls:** ← / → buttons (or arrow keys, space, swipe on mobile) · **F** fullscreen · **M** sound on/off

Videos autoplay muted and loop on each slide; use the sound button to hear clips that have audio.
Hosted with GitHub Pages from the `main` branch.
